# Used Car Price Prediction using ANN

A deep learning regression project for predicting used car selling prices using an Artificial Neural Network.

## Project Overview

The objective of this project is to estimate the selling price of a used car based on the available vehicle-related features in the dataset.

The project covers data exploration, preprocessing, feature preparation, Artificial Neural Network development, model training, and regression evaluation.
